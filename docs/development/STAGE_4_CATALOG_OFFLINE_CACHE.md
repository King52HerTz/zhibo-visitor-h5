# 阶段 4：馆藏目录同步与离线缓存

## 目标

让游客端在管理端目录尚未接入前先具备稳定的数据同步边界，并保证网络中断不会破坏最近一次成功内容。

## 已完成

- 游客网关新增公开馆藏目录和展品详情接口；
- 目录使用内容摘要生成版本号，并通过 `ETag` / `If-None-Match` 避免重复传输；
- 会话能力声明已开放 `exhibits`；
- H5 启动后缓存优先展示，同时在后台检查新版本；
- 新目录会在完整校验后一次性写入本机，失败时继续使用上一版；
- 探索、详情、首页推荐、AI 导览上下文、数字展册和来源页统一读取目录服务；
- 页面展示正在同步、已是最新、本机缓存、离线浏览和内置首版状态；
- 离线页允许继续浏览最近缓存的展品。

## 公开接口

- `GET /api/visitor/v1/catalog`：返回当前完整公开目录，支持条件请求；
- `GET /api/visitor/v1/exhibits/{exhibit_id}`：返回单件已发布展品；
- 未命中的展品返回 404，未知接口仍不会转发到管理端。

## 数据安全边界

- 目录响应只包含游客可见字段，不包含草稿状态、内部编号、权限或存储路径；
- 浏览目录不需要创建游客会话；
- 浏览器只有在整包结构校验成功后才替换旧缓存；
- 当前三件内容仍是内置首版演示资料，不冒充已接入的馆方生产数据库。

## 验证

- 游客网关测试覆盖目录公开字段、版本复用、详情查询和未发布内容拒绝；
- 前端通过 TypeScript 类型检查和 Vite 生产构建；
- 管理端发布接口完成后，只需在游客网关的目录提供者处替换内置首版，无需重写页面。
